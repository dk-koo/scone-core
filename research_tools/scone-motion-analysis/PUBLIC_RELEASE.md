# Public release scope

This directory contains a copy of the repository owner's SCONE/OpenSim motion analysis application source (`SCONE_analysis_v1` from their private research workspace) released as a community tool. It is maintained by `dk-koo`, independently of the upstream `tgeijten/scone-core` project. The Apache-2.0 license at the fork root applies. The upstream SCONE developers are not represented as authors/maintainers of this addition.

No study results, participant data, licensed Hyfydy assets, SCONE model binaries, optimization outputs or secret credentials are distributed. Installation is documented in README.md; downstream users must supply their own data and verify scientific interpretation. This project analyzes existing motion data. It does not conduct CMA-ES optimization or run SCONE on its own.

This public tree is not proof of widespread adoption or ongoing independent OSS maintenance. Contributions and reproducible bug reports are welcomed.
